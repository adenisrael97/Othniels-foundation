# Project Guidelines

## UI Components
- Always use reusable components for buttons, cards, inputs
- Do NOT hardcode UI elements inside pages

## Button Rules
- Use <Button /> component from /components/ui/Button
- Buttons must support variants: primary, secondary, danger

## Card Rules
- Use <Card /> component from /components/ui/Card
- Do not repeat layout styles in pages

## Code Style
- Keep components modular and reusable
- Avoid duplication
- Follow clean React component structure

## Architecture
- Pages = composition only
- Components = reusable UI logic
